Projects, funding & support

A staged programme for RNA manufacturing innovation.

RNA Forge advances defined RNAbox and service-development projects through innovation funding, strategic collaboration and investment aligned to practical technical milestones.

Start a conversation

Innovation funding

Project-led support for deployable technology.

RNA Forge structures supported work around defined technical outcomes, including prototype engineering, analytical integration, system refinement and pilot deployment preparation.

This approach links each work package to an evidence need and deployment decision, giving funders and collaborators a clear view of scope, milestones and intended outcomes.

Project timeline

From workflow definition to partner-led evaluation.

The programme uses stage-gated development so technical evidence and deployment readiness can be reviewed before the next commitment.

  1. Phase 1

    Workflow definition

    Translate manufacturing and analytical bottlenecks into platform requirements and defined development work packages.

    Programme foundation
  2. Phase 2

    Prototype refinement

    Refine modular hardware, integrated workflows and the interfaces needed to connect analytics and control.

    Current focus
  3. Phase 3

    Pilot preparation

    Define representative workflows, deployment requirements, test plans and partner responsibilities.

    Next milestone
  4. Phase 4

    Partner-led evaluation

    Evaluate integration and performance using agreed workflows and real system data before broader deployment decisions.

    Planned stage
